# Дополнительная документация

Служебные сведения: скрипты, порты, переменные окружения, эндпоинты API и порядок проверки.

## Скрипты

### Фронтенд (корень репозитория)

| Команда | Описание |
| --- | --- |
| `npm run dev` | dev-сервер Vite (по умолчанию http://localhost:5173) |
| `npm run build` | проверка типов (tsc) + сборка продакшн-версии |
| `npm run preview` | предпросмотр собранной версии |
| `npm run lint` | запуск ESLint |

### Бэкенд (`server/`)

| Команда | Описание |
| --- | --- |
| `npm run dev` | запуск через nodemon (автоперезагрузка при изменении файлов) |
| `npm start` | запуск в обычном режиме (`node index.js`) |

## Порты

- Фронтенд — `5173` (Vite по умолчанию).
- Бэкенд — `3001` (меняется через переменную `PORT`).

В dev-режиме фронтенд проксирует запросы `/api/*` на `http://localhost:3001` (см. `vite.config.ts`).

## Переменные окружения (`server/.env`)

| Переменная | Описание | По умолчанию |
| --- | --- | --- |
| `PORT` | порт сервера Express | `3001` |
| `CORS_ORIGIN` | разрешённые CORS-источники через запятую; `*` — любой источник | `http://localhost:5173` |
| `GREEN_API_URL` | хост green-api | `https://4100.api.green-api.com` |
| `GREEN_API_ID_INSTANCE` | id инстанса | — |
| `GREEN_API_TOKEN_INSTANCE` | токен инстанса | — |
| `GREEN_API_POLL_INTERVAL` | интервал опроса уведомлений, мс | `2000` |

## Эндпоинты API

| Метод | Путь | Описание |
| --- | --- | --- |
| GET | `/api/health` | проверка работоспособности + uptime + состояние инстанса |
| GET | `/api/instance-state` | состояние авторизации инстанса green-api |
| POST | `/api/auth` | установка и проверка учётных данных инстанса (форма входа) |
| GET | `/api/messages` | состояние в памяти: `{ chats, messages, instanceState }` |
| POST | `/api/send` | отправка сообщения; тело `{ "chatId": "...", "message": "..." }` |
| POST | `/api/webhook` | эндпоинт вебхука (в потоке HTTP API не используется) |

## Проверка работы чата

1. Запустите бэкенд: `cd server && npm run dev` (порт `3001`).
2. Запустите фронтенд: `npm run dev` (корень репозитория, порт `5173`, проксирует `/api` → `:3001`).
3. Откройте http://localhost:5173.
4. Отправьте сообщение привязанному Telegram-аккаунту с другого аккаунта — оно появится в чате в течение ~2 секунд.
5. Ответьте из интерфейса или начните чат через «+», указав `chatId` (номер, `phone@c.us` или `@username`).
